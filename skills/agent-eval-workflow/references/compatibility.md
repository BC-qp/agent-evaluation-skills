# 兼容与便携使用

核心指令是UTF-8 Markdown。支持 Skill 的宿主可加载完整目录；其他智能体可读取 `SKILL.md`，按入口链接加载参考文件。是否自动发现、注册或热重载取决于宿主，按其当前说明操作。

可选辅助脚本只使用 Python 标准库，建议 Python 3.10 或更高版本。命令从 Skill 目录执行，任务输出路径由调用者传入。不得把作者电脑的路径写进任务提示词。

- Windows：中文路径使用 Unicode 文件接口或 PowerShell 的 `-LiteralPath`，输入输出显式UTF-8。操作前解析目标路径，清理范围限制在已授权目录。
- 其他系统：使用相对路径与当前shell语法，不假设特定盘符或用户目录存在。
- 云端：先确认文件读写与工具执行能力。只有 Markdown 加载能力时按规则人工检查，不声称脚本已运行。

运行器的实时版本、启动命令和会话位置需现场核对。本包不承诺所有宿主均已测试。
