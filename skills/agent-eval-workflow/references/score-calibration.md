# 独立评分与横向校准

先按本次实际分制判断。下文数字仅演示10分制下的推理方式，不是其他分制的固定分档。

第一步按任务要求、实际完成程度和已核验的缺陷，为每个模型的每个计分维度确定合理范围。例如证据支持5至7分，就在该范围内进一步判断；范围由具体材料决定，不统一预设。先记录缺陷影响和剩余可用性，暂不因其他模型的分数改变事实。

第二步在同题、同维度内比较表现，形成有理由的相对次序，再按本次分制确定结果。产物重点比较核心目标受损程度、影响范围、错误结论的误导性、剩余可用部分和修订工作量；过程重点比较理解与实施是否偏离、修复是否引入新问题、是否有效利用已经出现的反馈，以及核验和交接是否可靠。过程比较须使用实际Session，不能从最终错误反推全部执行表现。

质量接近时，横向比较是定分步骤，不能用“都需要修改”把明显不同的表现统一压成6分。例如两份产物都落在5至7分范围，一份只需重做局部计算，另一份必须重建核心接口，分数应体现这种差别。4分或更低也须有核心内容、可用性或执行行为明显失效的证据，不能仅为补齐排名使用。

过程分先整理实际行为及其后果，再映射到分数，初判时不拿产物整数分作为参照。尤其区分：发现问题后修复并复验；只漏掉某类检查；已有结果指出矛盾却未用于修正；修补引入新错误，或改变检查条件而未保住原验收目标。修改验收器本身不自动扣分，要核对新条件是否仍符合任务要求，是否补齐相应负例。产物保留缺陷与过程存在有效恢复可以同时成立。

当前任务书和明确适用的口径决定是否限制同分或分差。没有要求时允许证据支持的同分，不设置差异配额。

先遮去产物分，只根据Session确定过程质量范围，再在各自证据支持的范围内作同题比较；仅核对当前明确适用的量化限制。区分漏掉检查、已取得证据却未修正结论、降低验收目标、成功排障并回到原目标复验等行为；产物比较核心目标受损、误导程度、剩余可用性和修订工作量。不得为拉开分数编造问题、夸大影响或更改事实。若现有证据不足以支持高低或同时满足限制，继续核验关键差异；仍无法解决时向用户说明具体冲突，不强行造分。

确定分数后逐一核对同维度相邻模型，确保高低有实际影响依据，且分数仍在各自合理范围内。只核对本次明确要求的分制和约束，不从其他任务引入配额。修订同步汇总表、维度标题及给分正文；保留已有事实、引用和证据位置，仅作与新分数相关的必要措辞调整。比较及计数在内部完成，项目方正文不新增排名、总分或人为权重。

过程检查覆盖需求理解、材料读取、研究、实施、工具使用、恢复、核验及交接等实际发生的环节，不只看自检。产物从文件清点深入事实、计算、来源对应、逻辑、跨文件一致性、可运行性、视觉表现及使用体验，按任务RUBRIC检查关键要求。教程另查学习输入、操作、预期输出及验证方法；代码另查关键功能和边界；动态作品另查连续运行或视频。不要用文件数、篇幅或README承诺代替验收。
