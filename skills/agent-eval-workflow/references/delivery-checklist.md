# 排版与交付检查

- 模型标题二级“模型名｜运行ID”；维度三级并重复模型名；标签、备注、证据及截图标题四级。沿用本次评测字段，不擅增维度。
- 维度之间保留清楚的段落间隔，复制框编号之间不空行，不插HTML换行。相邻截图用“——————”，模型间用“---”。截图标题“截图1｜第几条｜简短证据名称”，按本栏重新计数。
- 每个任务一份主评分稿，按本轮授权范围逐模型验收。必要证据与脚本按需保留，不额外创建检测报告、验收报告、修改说明、JSON录入稿、注意事项文档或平行校准版，不擅自打包新附件。
- 本包参考文件与模板共同维护。修改规则时同步检查模板和引用，消除冲突；修改具体评分稿不等于授权修改通用规范。
- 新评测只在稿首必要说明中记录本次评测适配，不复制一套批次版标准和模板。具体成绩、任务ID、本次评测标签和材料清单留在任务记录及本次评测来源中，不固化成通用要求。

## 交付前检查

1. 本次评测来源、表单与实际输入已对齐，范围与轮次无偷换，未套旧分制或标签。
2. 每个维度已独立确定证据与质量范围，再作同题比较；同分和分差仅核对当前明确要求，不擅自启用历史配额。高低与差距均有真实依据，未编造问题或机械配分。标签按实际行为匹配，集中使用“自测不充分”已回查；汇总表、维度标题和正文一致。
3. 产物关键要求与多个过程环节实际检查；教学模拟、原执行和本机复核没有混淆，未预设未验收模型成绩。
4. 横向检查本次所有稿件的给分句与反馈，未固定末尾报分、套用同一句子骨架或把反馈写成近似等长段落；高分反馈简练，低分按实际使用障碍充分展开，且不重复前两栏。仅润色时不改变事实、分数和证据；获授权重新评分时逐项复核变更依据。
5. 复制框仅含项目方正文，用户说明只在稿首且简短，无新增栏目或额外报告。
6. 每张证据直接支持备注，原文真实、来源清楚、上下文充分，数量符合本次评测要求；不存在为形式统一损失信息。
7. 文件链接与命令可用，PowerShell每处一行、一次回车，操作直接定位；证据标题简明准确，复测条件未隐藏。全画面路径痕迹检查与输出核验如实区分，原图及模型原文件未改。
8. 正式提交与发布按用户授权及本次评测要求执行，辅助写稿不冒充专家亲自验收。
