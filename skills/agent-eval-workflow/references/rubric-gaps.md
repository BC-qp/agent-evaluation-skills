# RUBRIC不完整时的处理

先读任务提示词、附件、已有RUBRIC和本次通用评分规则，区分“缺少标准文字”与“任务没有要求”。

1. 有明确任务要求而RUBRIC未覆盖时，可用适用的通用标准核对准确性、完整性、指令遵循和可用性，并标明依据。
2. 任务未要求的功能、专业能力、视觉偏好或运行条件不能临时加成评分维度。
3. 缺少权重、分制或映射时，不自行计算。先列已核验事实与需要确认的口径；用户明确要求设计自定义标准时再写，并与官方字段分开。
4. 模糊项先把可观察行为和影响说清；不能用漂亮措辞掩盖标准不足。
5. 不把缺失记录直接记为失败，也不因标准不完整默认满分。

内部覆盖表记录“要求出处、已有标准、适用通用原则、证据、待确认项”。最终报告只保留读者判断所需的说明。
