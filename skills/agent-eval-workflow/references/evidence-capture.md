# 截图与命令取证

同时阅读[取证红线](evidence-redlines.md)。按需使用[证据索引与截图操作卡](../assets/templates/evidence-index.md)。

### 形式由证明需要决定

- 可使用原文件局部、原图、原生表格或页面、真实终端连续原文、代码片段、多文档对照及实际运行输出。不要把全部证据机械统一为终端或某一种形式。视觉、版式问题展示原产物；文档与实现不符展示对照；计算问题保留输入、公式或代码及实际结果。
- 高保真要求保留所选证据的原文、结构、顺序、换行、条件及上下文，不代表必须输出整份文件。连续原文不改写；多来源可同屏分区，各自标明原文件名或产物内相对路径、范围，不拼成假连续文本，不夹入评审分析，不事后合成图片。
- 由评审者预先定位。打开或一次运行即可看到相关内容，不让用户搜索或翻几百行，也不把十几行手动定位交给用户。展示范围可稍宽于最终框选范围，保留函数、参数、分母、表头、相关调用与返回。既不摘得过短，也不塞无关长篇。
- 原图足够时逐张提供原文件和可点击链接，不生成、重绘、拼接、压缩、裁切或加标注替代原图，除非用户明确要求。原图复制核对源与目标的字节数、SHA-256及对应关系，哈希不能代替内容验收。动画和稳定性结论需真实运行或连续视频，静态图只证明所见画面。

### 数量与操作

数量按本次要求和证明需要决定，不预置统一张数，不强制每条配图，不凑数量。同一稿中同一上传图不跨栏重复使用；已有图先查能否复用，其他已核验发现保留定位。检查深度与图片数量分别处理。

“证据与截图位置”下直接接截图标题，每张仅保留“打开、框选、保留”；后两项可合并。“打开”放已验证的文件链接及定位，或完整可一次粘贴的实测代码，不另设“运行、取用、源文件、另已核对”等字段。两图共用命令时只运行一次，截图2在“打开”中说明对应输出，在“框选”中明确区域。每张须有独立用途，无必要的第二张删除。

使用PowerShell取证时，每处只给一行调用，粘贴一次、回车一次即可看到证据。中文编码、窗口标题、清屏、提示符和环境加载放进配套脚本，不要求用户再输入初始化命令或逐段回车。脚本路径与所需材料一起核验，不能只保证命令看起来短。

### 无本机环境痕迹与真实复核

最终截图所有位置都不得露出评审者盘符、用户名、评审者工作目录或批次目录，包括窗口标题、地址栏、命令回显、来源、结果、报错堆栈及首尾提示符。绝对路径可留在内部读取逻辑、用户运行命令和评分稿链接中；展示仅用原文件名、产物内相对路径或事件编号。取证前配置干净视图，处理历史输出和提示符，不依赖用户逐处裁切或遮挡补救。

不修改模型原始文件，不隐藏影响判断的错误，不暗改原始记录中有意义的路径关系。若证据原文与隐去环境信息存在冲突，改选合适视区或展示方式，并在必要时于稿首简述限制，不能伪造原文。

命令只能读取原文、源代码、原始字段、原生元数据或产生可复核计算，不能把作者写好的评价打印成证据，不能制作仿终端图。本机复核结果与模型原结果分开标明，不把评审动作冒充模型执行。

展示标题使用简短、准确的来源名称，例如“原始Session”“源代码”“本机复测结果”，保留运行ID及文件或事件位置。不使用“独立边界复跑（原代码，临时状态）”这类含义不明的操作说明，也不把混合来源窗口统称“原文证据”。本机复测的身份不能为了截图简洁而隐藏；涉及构造状态、测试替身、方法提取或特殊参数时，应保留影响判断的具体条件，避免把人为构造的测试误写成模型原始运行。标题不能附带预写评价。是否符合项目提交要求须依据本次评测规则判断，不能仅凭标题承诺一定合格或认定一定不合格。

命令逐条实测，核对中文、引用范围、来源、依赖、错误输出与关键上下文。中文显式使用UTF-8，兼容Windows PowerShell的脚本按需使用UTF-8 BOM，减少重复加载大文件。输出检查与窗口实看分别核验；未实看不能宣称全画面无路径或截图已验收。检查记录内部完成，不另产给用户看的检测报告。
