# 完整来源回溯

本包提供通用方法，不附带任何组织的完整任务书或评分标准。用户要找、翻译或解释原标准时，不能把本包摘要、适配规则或空白模板当作原文。

1. 先定位用户提供的任务书、标准链接、附件清单和工作区索引。
2. 区分完整源标准、方法摘要、字段适配和输出模板。
3. 在已授权范围内按标题、章节线索、版本和适用任务检索；不要假设存在作者的私人来源目录。
4. 找到多个候选时比较版本、适用范围与冲突。无法确认当前来源时明确缺口，不用历史内容补成官方口径。
5. 返回可访问的真实来源与位置；需要翻译或总结时处理完整原文。内部源链接不进入公开 Skill 或教学案例。

实际评分前核对分制、字段、标签、是否计分、轮次、提交要求及AI辅助边界。没有给分规则且用户只要证据整理时，先交事实；受托设计自定义规则时标明其身份，不混入官方字段。
