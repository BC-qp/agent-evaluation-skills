# 虚构评分示例

以下情境、数字和事件位置均为教学构造，不代表真实模型成绩或历史评测。

## 产物与过程分开判断

任务要求依据附带规则生成社区借物清单。虚构产物漏掉一条已到期记录；虚构轨迹显示执行者发现过日期解析失败，随后修复解析并只检查总行数，没有核对逐项清单。

- 产物栏说明漏项导致清单不能直接用于逐项核对，定位清单与输入对应行。
- 过程栏说明实际执行了修复，但复验只覆盖总行数，未覆盖到期条件。依据是具体事件与检查内容，不是从漏项反推“从未检查”。
- 若没有轨迹，只保留产物结论，并列出过程评价所需材料。不得补造过程分。
- 没有给定分制和评分规则时，本例不附分数。重复问题是否跨维度评价，取决于两栏是否各有独立依据。

## 恢复后的报错

一次文件读取失败后，执行者改用正确编码重读，核对关键字段并完成原目标。这段事实支持说明有效恢复，不能仅因日志出现一次错误就判定运行不稳定。

## 自然表达

空泛句：“整体内容较为全面，但仍有一定提升空间。”

具体句：“待归还清单漏掉一条已到期记录，管理员按该表追踪时会遗漏对应物品；其余记录仍能与输入逐项对应。”

另一种发现：“汇总金额计算正确，但没有标明使用的到期日期规则。接手者无法判断同一天归还的记录应计入哪一组。”

按具体发现决定篇幅与句序。不要只换名词循环使用同一句式，也不要为显得不同而改变事实。反馈栏补充前两栏未展开的使用发现，不重复扣分理由。
