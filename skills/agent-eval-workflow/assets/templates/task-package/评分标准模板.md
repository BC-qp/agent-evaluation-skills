# 任务包评价口径设计模板

仅在用户要求设计评价口径时填写；不是实际评测的官方评分标准。已有官方标准时直接引用，不填新分制或维度。

## 来源与适用范围

- 官方标准或用户授权：
- 实际输入、任务目标与允许边界：
- 计分维度及分制（仅填写来源或授权要求的字段）：
- 标签、权重或封顶（仅明确要求时填写，否则删除）：

|---|---|---|---|
|  |  |  |  |

## 独立判定

各维度按自身事实和影响判断，不把错误条数或工具数量换算成分数。实际评分稿回到已安装的 `agent-eval-workflow` 读取 `references/scoring-contract.md` 与 `assets/templates/scoring-report.md`，不要把模板所在skill的相对路径当作生成任务包内的路径。
