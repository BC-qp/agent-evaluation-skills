# 提纯任务包文件骨架

复制本骨架或让脚本/智能体生成以下五个文件。每个方括号处为需填写内容。

---

## prompt.md

```markdown
# 任务：<一句话目标>

## 背景
<脱敏后的真实业务上下文，只保留完成任务所需信息>

## 输入材料
<相对路径或内嵌材料；使用约定的只读输入副本>

## 你的任务
<目标、不可违反的边界、必要约束。不要写逐步答案>

## 交付物
- <文件/产物名>：<格式与位置>

## 验收标准
- 硬门槛：<能打开/能运行/关键结果正确>
- 质量核查：<如何重新验证>

## 护栏
- <高风险/不可逆操作的限制>
- <做不到时最低要保留什么>

## 完成说明
不要伪造工具、过程记录、截图或未验证结论；遇到阻塞时如实说明已完成部分与证据缺口。
```

## design_notes.md

```markdown
# 任务设计说明

## 保留的真实难点
- <业务判断点1>：为什么它能区分模型能力

## 刻意留空的决策空间
- <方案/工具/信息组织/异常处理/质量取舍>

## 粒度取舍
- 为什么不过宽：<有具体输入、产物、验收>
- 为什么不过死：<步骤和工具链未被规定>

## 公平性声明
- 提示词不含标准答案或隐藏解法；不针对任何模型名称或已知弱点调整。
- 只有 prompt.md 与必要脱敏输入会交给执行者；本文件及其余内部记录不随题下发。
```
