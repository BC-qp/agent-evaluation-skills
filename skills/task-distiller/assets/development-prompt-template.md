## 模板使用前的内部检查（不复制给执行模型）
1、先读取本次评测任务书，沿用用户确认的格式；历史题只作结构参考，不复制旧题业务和过期规则。
2、按“一次批读→通用生成器→统一检查”压缩任务：若压缩后大部分已完成，继续寻找真实业务决策、跨模块依赖和反馈回路；不要用多文件、多截图、多样本或强制过程灌水。
3、加深任务时同步补齐仓库中的真实数据、可运行复现、反例和验收入口；仅增加形容词或报告数量不算加深。构造输入标明来源性质，正常控制用于排除错误预期。
4、任务维度、编号条目和RUBRIC之间建立覆盖关系；条目写独立结果，避免多个段落反复要求同一件事。
5、内部工作量目标只留在设计记录。未实跑时给出不确定性，不承诺工具次数，不把测试数、文件数或脚本内部循环换算成调用量。
6、保留实现自由度；输入材料需要答案核对时说明语义，但不要向执行模型附带私有评分、参考解法或编造的成功报告。
